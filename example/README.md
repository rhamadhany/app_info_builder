# example_app — `app_info_builder` Demo

A minimal Flutter app that verifies the [`app_info_builder`](../) plugin works correctly.

## What it demonstrates

The home screen displays every field generated by the plugin at build time:

- `version`, `buildNumber`, `fullVersion` — from `pubspec.yaml`
- `appName`, `packageName` — from `AndroidManifest.xml` & `build.gradle.kts` (Android host only)
- `buildTimestamp` — UTC ISO 8601 (optional)
- `extra.buildFlavor`, `extra.apiEnv` — from `extra_fields` in `app_info.yaml`

## How to run

```bash
flutter pub get
flutter run
# or build for a specific platform:
flutter build apk --debug
flutter build linux --debug
```

During the build, the platform hook (Gradle on Android, CMake on Linux)
runs automatically and writes:

```
lib/generated/app_info.dart    ← DO NOT EDIT (regenerated on every build)
```

## Configuration

See [`app_info.yaml`](app_info.yaml):

```yaml
class_name: ExampleAppInfo
output: lib/generated/app_info.dart
include_git_hash: false
include_build_timestamp: true
extra_fields:
  buildFlavor: debug
  apiEnv: staging
```

## Manual regenerate

```bash
# from the example/ folder
dart run app_info_builder:generate
```

Or via the platform hook:

```bash
# Android
cd android && ./gradlew :app:generateAppInfo
```

## Verification

1. Delete `lib/generated/app_info.dart`.
2. Run `flutter build <platform>` (apk / linux).
3. The file reappears before the platform compile step finishes.
4. Open the app — all metadata is shown on screen.
